# Bao Admin 1.0

- Админ-консоль в личке с выбором группы.
- Варны, муты, баны, снятие наказаний.
- Удаление и закрепление сообщений.
- Русские команды и команды со слешем.
- Антифлуд, фильтр ссылок, приветствия, правила, жалобы.
- Настраиваемые лимиты и журнал действий.
- Каталог премиум-эмодзи для каждой группы.
- Команда /emojiid для извлечения ID.
- Редактор текстов с предпросмотром и прямой вставкой премиум-эмодзи.
- Обычные эмодзи на замену при отказе Telegram.
- Выключатель автоматических функций для группы и режим техработ.
- Проверка прав при каждом действии, защита администраторов.
- SQLite, Docker и запуск на Python-хостинге.
- Длинные тире в сообщениях заменяются на дефис.
