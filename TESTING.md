# Проверки Bao Admin 1.0

33 автоматических теста успешно выполнены на Python 3.12.

Проверены права модераторов, отказ обычным участникам, защита админов, старые кнопки, редактор после снятия админки, разделение групп, сохранение SQLite, сроки мутов и пределы, варны и сброс только после успешного мута, безопасный разбан, стандартные права при размуте, флуд командами, скрытые и отредактированные ссылки, выключение автоматических функций, жалобы, UTF-16, премиум-эмодзи из текста и подписи, командный редактор и обычная замена эмодзи при отказе Telegram. Размер callback_data укладывается в лимит Telegram.

API Telegram подменялся в тестах. Реальные сетевые наказания, отправка премиум-эмодзи и развёртывание на BotHost не проверялись: токен нового бота не предоставлен.

Повторить: python -m unittest discover -s tests -v
